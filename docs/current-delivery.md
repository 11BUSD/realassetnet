# Current delivery and remaining gates

## Available now

- Full-width, keyboard-accessible record inspectors across audit, ledger, evidence provenance, factory runs and private network views. Nested JSON is decoded for reading; the download preserves the stored record.
- Toronto/GTA private intake for residential and commercial property categories, explicitly distinguishing synthetic fixtures from contributor-provided real information.
- Contributor source and authority statement stored separately and immutably. This statement is not a legal determination or verification of ownership.
- Text/CSV proposed numeric claims and exact accepted UTF-8 payload hashing; confirmation, contradictions, independent reconciliation and versioned underwriting.
- Original PDF/Office/image bytes retained in private quarantine with signatures, size limits and hashes. The HTTP server never executes a parser. An operator-only isolated scanner now gates passive PDF/CSV/XLSX review; Numbers archives are preserved and inventoried, without decoding their tables.
- Reviewed synthetic public passports, separate access and eligibility gates, simulated property participation, fees, holdings, distributions and audit integrity.
- Read-only institutional organization, score, documented relationship and daily preparation queue views. Administrator sign-in plus a separate operator key is required. Source research remains outside the public application project.
- Factory skills, invariant tests, publication checks and source-hash release evidence.

## Needed from the operator or real transaction

Private source files have been received and retained outside the project. Their source rights, observation dates and material fields still require review before supporting a real package. No synthetic listing should be represented to a counterparty as a real asset.

An institutional discovery conversation can use the software demonstration and the source-backed relationship research. It should establish current mandate, information requirements, recipient authority and a narrowly scoped pilot. The preparation queue does not send or imply contact consent, capital availability or partnership.

## External approvals and services

Actual legal/regulatory qualification, listing and data rights, professional opinions, licensed KYC/title/custody/payment providers and live financial permissions cannot be created by a software status change. Real property publication and all live financial executors remain disabled. The existing simulated demo stays usable while these gates are resolved.

## Identity and provider delivery

A signed review bridge and a synthetic-only KYB adapter are implemented and tested; vendor accounts, contracted access and live sandbox verification are not complete. Provider receipts cannot grant eligibility or trigger financial execution. See identity.md and providers.md.
